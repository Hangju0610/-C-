## long long, 8바이트짜리 정수
- 범위는 –9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807
- int로 표현이 안될 때 사용

INF와 비슷한 이유로 1e18로 정의를 해놓고 쓰면 되나, 이는 문제마다 다르니 참고

typedef long long ll;
ll INF = 1e18;

double이 더 정확하게 표현가능하니 double로 사용한다.
