## 배열과 연결리스트 비교

### 배열
- 연속된 메모리 공간에 데이터를 저장
- 삽입, 삭제에는 O(n)
- 참조는 O(1)

### 연결리스트
- 연속되지 않은 메모리 공간에 데이터 저장
- 삽입, 삭제에는 O(1)
- 참조는 O(n)

### 결론
데이터 추가와 삭제를 많이 하는 것은 연결 리스트
참조를 많이 하는 것은 배열로 진행

### 왜 연결리스트의 삽입과 삭제는 O(1) 인가요??
특정 위치에 삽입 또는 삭제를 하는 경우, 해당 위치의 바로 앞 노드를 찾아야 하므로
원칙적으로 O(N)의 시간이 걸립니다.

하지만, 삽입 또는 삭제할 노드에 이미 접근했다고 가정 했을 때
(이미 특정 노드를 가리키고 있는 포인터가 있다고 가정할 때)를 기반으로 이 작업의 시간 복잡도를 계산합니다.

이 때 해당 노드의 포인터만 조정하면 되므로 O(1)의 시간이 걸립니다.

### 왜 배열의 삽입과 삭제는 O(N)인가요?
배열의 중간에 원소를 삽입하거나 삭제하는 경우, 해당 원소 이후의 모든 원소를 이동시켜야 하므로
평균적으로 O(N)의 시간이 걸립니다.
즉, 추가하거나 제거할 때 나머지 원소들의 위치를 조정해야 하는 시간이 걸린다.
